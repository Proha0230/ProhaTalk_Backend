# Версия 0.6

## Изменения

1. Добавлен функционал записи времени выхода пользователя из аккаунта:

    - теперь другие пользователи могут видеть время последнего онлайна

2. Дополнен response пользователя в разделе поиска пользователей:

    - информация о наличии дружбы

    - информация об отправленной заявке в контакты

3. Проведена оптимизация backend-архитектуры:

    - добавлен переиспользуемый модуль `universal`

    - снижена дупликация кода

    - улучшена поддерживаемость проекта

    - повышена безопасность и читаемость кода

4. Усилена безопасность API:

    - все запросы с лишними параметрами, которые backend не ожидает, теперь возвращают ошибку `400 Bad Request`

    - включена строгая валидация входящих DTO
